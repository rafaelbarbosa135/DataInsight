# DataInsight

Aplicação web desenvolvida em Python para carregamento e visualização inicial de dados a partir de arquivos CSV e XLSX.

O projeto está sendo desenvolvido como parte da minha jornada na Engenharia de Software, com foco no aprendizado de Python, análise de dados e, futuramente, Inteligência Artificial e Machine Learning.

## Funcionalidades atuais

- Upload de arquivos CSV
- Upload de arquivos XLSX
- Leitura dos dados utilizando Pandas
- Exibição de uma prévia dos dados
- Interface web desenvolvida com Streamlit

## Tecnologias utilizadas

- Python
- Pandas
- Streamlit
- OpenPyXL
